# Part 1: 의약화학 (Medicinal Chemistry)

## 1. 의약화학 전체 커리큘럼 (Phase 8)

| Phase | 주제 | 핵심 질문 | 연결되는 기존 학습 | 
| ----- | ---- | -------- | ---------------- |
| 1 | 의약화학이란 무엇인가(기초 개념) | "약은 도대체 무엇이고, 어떻게 만들어지는가?" | - |
| 2 | 약물의 분자 구조와 물리화학적 성질 | "분자의 어떤 성질이 '약'이 될지를 결정하는가?" | 유기화학(작용기, 결합) | 
| 3 | 약물-표적 상호작용 | "약은 몸 속 무엇에, 어떻게 달라붙는가?" | 독성학(독성역학/toxicodynamics) |
| 4 | 약동학과 ADME(의약화학 관점) | "약이 몸 안에서 어떻게 움직이고 사라지는가?" | 독성학 (ADME) |
| 5 | 약물 설계 전략 (SAR, 파마코포어) | "효과 좋은 분자를 어떻게 '설계'하는가?" | - |
| 6 | 주요 약물 분류와 작용 메커니즘 | "실제 약들은 어떤 원리로 분류되는가?" | - |
| 7 | 신약 개발 과정과 전산 의약화학 (CADD) | "후보 분자가 어떻게 진짜 '약'이 되는가?" | 개발자 배경 (알고리즘) |
| 8 | 고급 주제 (바이오의약품, AI 신약 개발) | "지금 의약화학의 최전선은 어디인가?" | AI Native Builder 목표 |

> 분자가 무엇인지? (phase 1, 2)
> 그 분자가 몸의 표적과 어떠헥 만나는지? (phase 3)
> 몸 안에서 어떻게 움직이는지? (phase 4)
> 어떻게 더 좋은 분자를 설계하는지? (phase 5, 6)
> 실제 약으로 만들고 미래로 나아가는지? (phase 7, 8)
